# 0002. Вибір Prettier

* **Статус:** Відхилено (Declined)
* **Дата:** 2026-09-28

## Контекст (Context)
Необхідно забезпечити єдиний стиль форматування коду в команді та уникнути суперечок і витрат часу під час Code Review щодо форматування (відступи, лапки, переноси).

## Рішення (Decision)
Використовувати **Prettier** замість ручного форматування або застарілих форматерів.

Обґрунтування:
* Повністю автоматизує підтримку єдиного стилю коду в команді.
* Уникає суперечок щодо стилю під час review.
* Перевірений часом інструмент із великою екосистемою та підтримкою багатьох форматів файлів.

## Наслідки (Consequences)
* **Позитивні:**
  * Повна автоматизація форматування та економія часу на Code Review.
  * Просте підключення та єдині стандарти для всіх учасників розробки.
* **Негативні / Ризики:**
  * Обмежена кількість параметрів конфігурації (opinionated approach).
