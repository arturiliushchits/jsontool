# 0009. Вибір StrykerJS для mutation testing

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-10-22

## Контекст (Context)
Звичайні тести підтверджують очікувані результати, але самі по собі не показують, наскільки впевнено вони виявляють помилки в реалізації. Потрібен поширений mutation-testing інструмент із підтримкою JavaScript та `node:test`.

## Рішення (Decision)
Використовувати **StrykerJS** та його `tap-runner` для mutation testing нативних тестів Node.js.

StrykerJS обрано як широко популярне, усталене рішення JavaScript-екосистеми. `tap-runner` запускає файли `node:test`, що виводять TAP, без додавання іншого тестового фреймворку. Мутації обмежені тестованими ядром і патернами; mutation suite запускається окремою командою, а не кожним звичайним `npm test`.

## Наслідки (Consequences)
* **Позитивні:** Звіт показує, чи виявляють модульні тести навмисні зміни поведінки; зберігається `node:test` без додаткового runner-фреймворку.
* **Негативні / Ризики:** Mutation testing потребує суттєво більше часу, ніж звичайні тести; пережиті мутації вимагають ручного аналізу й класифікації.
