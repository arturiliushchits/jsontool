# 0007. Вибір Ajv для валідації JSON Schema

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-09-28

## Контекст (Context)
Для роботи з JSON Schema необхідний надійний інструмент валідації даних, який коректно підтримує всі специфікації (drafts).

## Рішення (Decision)
Використовувати бібліотеку **Ajv**.

Обґрунтування:
* Активний проєкт з великою кількістю контриб’юторів та якісною документацією.
* Зручний та зрозумілий синтаксис.
* Реалізовано підтримку всіх специфікацій (drafts) JSON Schema, що є критичною вимогою для інструменту роботи з цією технологією.

## Наслідки (Consequences)
* **Позитивні:**
  * Повна сумісність із JSON Schema стандартами.
  * Висока продуктивність завдяки компиляції схем у код.
* **Негативні / Ризики:**
  * Додаткова зовнішня залежність у проєкті.
