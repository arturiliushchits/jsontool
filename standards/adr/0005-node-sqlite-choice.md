# 0005. Вибір нативного модуля node:sqlite

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-09-28

## Контекст (Context)
Для роботи з базою даних у Node.js потрібен простий, швидкий та безпечний інструмент взаємодії з SQLite.

## Рішення (Decision)
Використовувати нативний модуль **`node:sqlite`** замість сторонніх ORM чи драйверів (на кшталт Sequelize чи `better-sqlite3`).

Обґрунтування:
* Відсутність зовнішніх залежностей.
* Зменшення ризиків уразливостей ланцюжка постачання (supply chain attacks).
* Максимальна швидкість роботи «з коробки» без додаткових накладних витрат.

## Наслідки (Consequences)
* **Позитивні:**
  * Нульові зовнішні залежності для роботи з базою даних.
  * Високий рівень безпеки та швидкодії.
* **Негативні / Ризики:**
  * Необхідність писати SQL-запити вручну без високорівневих абстракцій ORM.
  * Залежність від версії Node.js із підтримкою відповідного нативного модуля.
