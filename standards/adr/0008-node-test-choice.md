# 0008. Вибір нативного тестового фреймворку node:test

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-09-28

## Контекст (Context)
Для покриття коду тестами необхідний інструмент запуску тестів (test runner) без зайвого ускладнення конфігурації.

## Рішення (Decision)
Використовувати нативний тестовий фреймворк **`node:test`** замість зовнішніх бібліотек (Jest, Mocha тощо).

Обґрунтування:
* Відсутність потреби встановлювати важкі зовнішні бібліотеки.
* Миттєвий запуск тестів без додаткових конфігурацій та транспіляції.

## Наслідки (Consequences)
* **Позитивні:**
  * Висока швидкість виконання.
  * Менше залежностей у `package.json`.
* **Негативні / Ризики:**
  * Менша кількість вбудованих утиліт для мокінгу порівняно з Jest.
