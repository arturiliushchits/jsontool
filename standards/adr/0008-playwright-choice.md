# 0008. Вибір Playwright для end-to-end тестування

* **Статус:** Прийнято (Accepted)
* **Дата:** 2026-10-22

## Контекст (Context)
Для перевірки основних сценаріїв користувача потрібні браузерні end-to-end тести, які взаємодіють із реальною сторінкою та локальним API. Потрібне рішення з широким впровадженням, активною екосистемою та достатніми можливостями для сучасних браузерних сценаріїв.

## Рішення (Decision)
Використовувати **Playwright** для браузерних end-to-end тестів.

Playwright обрано як широко популярне та усталене рішення з більшим набором можливостей для браузерної автоматизації порівняно з Cypress: підтримкою Chromium, Firefox і WebKit, незалежними browser contexts, автоматичним очікуванням, завантаженнями та керуванням діалогами. Поточний набір запускає Chromium; інші браузери можуть бути додані за потреби.

## Наслідки (Consequences)
* **Позитивні:** Реальні користувацькі сценарії перевіряються у браузері; інструмент надає кросбраузерну автоматизацію та розвинені засоби керування сторінкою.
* **Негативні / Ризики:** Для запуску потрібні браузерні бінарні файли Playwright; браузерні тести повільніші й чутливіші до середовища, ніж модульні тести.
